To change something

Recognized phrases: core.js / signal. Appearance: style.css. Example conversations: fixtures.json. Input contract and correctness: tests/core.test.js.

A practice to reuse

A saved original HTML page exposed that the owner's avatar link contains no text. A search summary had also omitted the critical fourth comment. An actual source fixture caught both issues; a plausible example alone would not. Test the source format that failed, and keep uncertainty visible.
